# GPUJournal

**An independent GPU journal — cloud GPU rental prices, checked daily.**

**Site: [gpujournal.ai](https://gpujournal.ai)** · X: [@GPUJournalAI](https://x.com/GPUJournalAI)

GPUJournal tracks the cloud GPU rental market so that people who rent GPUs can see what things actually cost, on the record, with dates. We sell nothing — no GPUs, no rentals, no placements — and no provider can pay to be listed, ranked, or recommended.

## What the site does

- **[Compare prices](https://gpujournal.ai/compare-prices)** — verified on-demand rental prices for 20 GPU variants across the major GPU clouds, re-checked every day and stamped with the check date. Every priced offer carries a Launch link straight to the provider.
- **[Price Watch](https://gpujournal.ai/price-watch)** — every price rise and cut we catch, published with the old price, the new price, and the dates both were observed. In October 2026, one provider raised its prices seven times in eight days; all seven moves are on the record there.
- **[Models](https://gpujournal.ai/models)** — 150+ open-weight models, each with the memory maths worked out from its published parameter count (FP16, 8-bit and 4-bit, with headroom), the GPUs that can run it, and — when no single card is big enough — the smallest honest multi-GPU setup, priced as a whole.
- **[Guides](https://gpujournal.ai/guides)** — deploy-and-cost guides with the working shown: what a model costs to run per hour and per million tokens, when self-hosting beats an API, and where the catch is in a headline price.
- **[News desk](https://gpujournal.ai/news)** — GPU industry headlines, reported with real official images and named sources.

## How prices are verified

Prices are read from the providers' own published pages and checked against the previous reading before anything changes on the site. A figure we cannot verify is labelled **stated** — a provider's own claim, reported as such — and is never presented as a verified price. Each GPU variant gets exactly one **Best offer**: the lowest verified on-demand price. Spot prices are tracked separately and never mixed into that title.

## Why this repository is public

This repository holds the live site's files — what you see here is exactly what gpujournal.ai serves. The journal's method is its credibility, so its workings stay open to inspection.
